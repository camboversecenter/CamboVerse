NUM campus layout editor

Controls follow Canva's conventions. Click to select, Shift+click to add/remove items from the selection, left-click-drag on empty ground to box-select several at once. Drag any selected item to move it (or the whole group together); a plain click on one member of an ad-hoc (non-grouped) selection drops back to selecting just that one. Ctrl/Cmd+G locks the current selection into a real group — from then on, any member always acts as the whole group: clicking it selects everyone, and dragging it (even straight off, with nothing pre-selected) moves everyone — a grouped object can no longer be picked individually. Press Ctrl/Cmd+G again on a locked group to ungroup it (or Ctrl/Cmd+Shift+G — same thing). Arrow keys nudge the selection 1 m (Shift+arrow = 10 m). Delete/Backspace removes selected road(s) — buildings can't be deleted, only moved/resized. Escape deselects, Ctrl/Cmd+A selects everything, Ctrl/Cmd+Z undoes any number of changes. Select a resizable building and drag the gold corner box to resize it (or type exact Width/Depth in the panel). Select a rotatable building and drag the cyan circle on its stalk to spin it around its centre — a live degree readout follows the cursor, and holding Shift while rotating snaps to 15° steps (or just type exact degrees in the panel). With 2+ items selected, the same cyan handle appears above the whole group to rotate everyone around its shared centre (orbit and spin in place, Canva-style; roads just orbit), plus three gold scale handles at the group's bounding box — the corner handle scales width and height together (and road widths), while the side handles each scale just one axis (width-only or height-only), all away from the fixed opposite corner, including each building's own size where resizable. + Road / + Wall take two clicks (start point, end point); + Pool and + Building take one click to drop the footprint, which you then drag/resize/rotate like anything else. A wall is a road that stands up, so it also gets a Height; a pool is a water surface, so it has no facing. + Building places an instance of an existing 3D component — pick which one from the dropdown, since the editor can't invent new geometry. World units are metres — same coordinate system as BuildingsView.tsx. This editor only ever changes position / rotation / size / road layout — it never touches how a building is modelled.
