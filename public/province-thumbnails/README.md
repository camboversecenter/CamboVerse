# Province character thumbnails

128-pixel copies of the existing approved fictional AI character portraits in
`camboverse-provinces/`. CC BY 4.0, CamboVerse Provinces — CamboVerse Center.
Original artwork, songs, credits and the 25-character introduction remain in
their versioned source collection. Rebuild with
`scripts/prepare-production-preview-assets.py`. These small menu portraits avoid
downloading every full-size character image when opening the collection.
