walkthrough of the HTTPS preview. It is not a hardware acceptance sign-off.

## Changes

- Campus Overview explicitly restores its camera position, upright orientation
  and target when selected and after leaving VR. Selecting Overview again resets
  it and closes the previous landmark card.
- Campus phone controls use two header rows, with an independently scrollable
  location strip and at least 44-pixel navigation targets.
- On-screen Naga information labels stay clear of header/guide and walking
  controls. Anchors outside the viewport remain outside it.
- Buildings and campus raise quality to Ultra only during VR; exiting restores
  the visitor's previous choice. Opening or cancelling VR instructions no longer
  changes quality.
- Removed the stale "Seven buildings" text from the campus introduction; the
  directory already displays its current building count.

## Automated validation

- 85 Vitest files / 427 tests pass, including the new camera restoration,
  viewport placement and temporary headset-quality regressions.
- TypeScript and the production build pass. The existing large-chunk warning
  remains; this is not a low-end-device performance sign-off.
- Publish-safety scan passes for staged and working files; 8 scanner tests pass.
  No raw media, user documents or new binary assets are staged.

## Published capture integrity

All four HTTPS files returned bytes matching SHA-256 of the reviewed local files.
Normal files are about 5.76 MB each. These sizes are not a measured loading-time
or frame-rate result.

| Capture | Normal bytes | Ultra bytes |
| --- | ---: | ---: |
| Naga Staircase | 5,759,200 | 14,737,216 |
| Flower Clock | 5,760,000 | 7,898,656 |

Raw media, training files and local-only Campus Shrine capture exports are not
part of this release. The latter remains available for local review; the deployed
Buildings page uses the authored shrine model. The production main JavaScript
bundle is still roughly 0.90 MB compressed, so startup and capture streaming need
measurement on the target low-end Android/4G connection.

## Follow-up acceptance checks

   desktop, portrait and landscape sizes; walk, run, jump, return to Overview,
   open/close the guide and navigate to another building.
2. Visit Biology, Chemistry, Physics and Earth & Sky in Normal and Ultra. Test
   room selection, station notes, activities, and returning to the hub. Use the
   local `?vr-sim=1` mode to inspect panel layout and simulated inputs.
3. On Meta Quest 3, enter/exit/re-enter each room; test both rays, Y/Close,
   movement with the panel open, snap-turn, double jump, flight, station arrival
   and actual audible narration. Restore the prior desktop quality on exit.
4. Measure startup, draw calls/geometry, frame rate and memory on a low-end
   Android and Quest. No hardware performance claim is made by this pass.
5. Review Khmer/French/Chinese speech and text with native speakers. Scan gaps
   and blurred capture edges require capture cleanup or additional photographs.
