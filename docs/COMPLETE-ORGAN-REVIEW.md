# Complete organ-set review candidate

Generated by `scripts/build-complete-organ-review.py`. Outputs are local-only in
`public/models/local/complete-organs-review-v1*`. Existing live assets are unchanged.

## Scope and approval gate

Assembles all 19 existing teaching groups, including brain, heart, lungs and
airways, with the 15-group viscera set. This is the complete current lesson set,
not every structure of human anatomy. Liver, stomach and small-intestine shapes
are revised; other organs reuse their existing meshes.

Three review cameras provide front, side and back views. This is a proportions
review, not a medical validation or scan-derived model. Reference for digestive
relationships: https://openstax.org/books/anatomy-and-physiology-2e/pages/23-1-overview-of-the-digestive-system

The older heart asset has a different up-axis: rotate before positioning.
Lung shape keys are cleared in this static candidate before transforming mesh
vertices; retaining the untransformed keys would restore the original placement.
Production breathing animation must be transformed/rebuilt consistently on import.

User approval of these previews is step 4. Step 5 (replace app assets, generate
Normal/Ultra tiers and test selection/removal/return/detail) remains pending that
approval. Do not route the full high-detail review GLB into Normal mode.

Checks: all 19 IDs retained, finite vertex positions, GLB parses in Three.js.
The full set is 183,768 triangles. App performance and anatomical intersection
validation are not implied by these checks. Skin/skeleton fitting needs a further
overlay check before final integration; camera views alone cannot prove fit.
